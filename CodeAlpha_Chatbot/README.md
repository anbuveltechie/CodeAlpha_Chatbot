
# CodeAlpha Basic Chatbot

## Project Overview

CodeAlpha Basic Chatbot is a rule-based conversational application developed using Python.

It interacts with users through predefined responses and identifies common messages using conditional statements.

## Features

- Greeting detection
- Basic conversation handling
- Chatbot identity response
- Help command
- Unknown message handling
- Case-insensitive input
- Extra space and punctuation handling
- Exit functionality

## Technologies Used

- Python 3
- Visual Studio Code

## Concepts Used

- Functions
- If-elif-else
- While loops
- String handling
- User input and output

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute:

python main.py

## Available Commands

| User Input | Chatbot Response |
|---|---|
| hello | Greeting |
| how are you | I'm fine, thanks! |
| your name | Chatbot introduction |
| help | Available commands |
| bye | Exit message |

## Testing

The chatbot was manually tested with normal messages, uppercase inputs, extra spaces, multiple punctuation marks and unknown messages.
